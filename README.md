# Folhiê Visual Design

Crie o design visual de um site para uma marca de velas aromáticas chamada FOLHIÊ.

A marca deve transmitir uma sensação de aconchego, elegância, natureza e sofisticação, com uma estética inspirada no Pinterest, em decoração de interiores e em marcas sofisticadas de velas e aromas.

Utilize uma paleta de cores com verde escuro, off-white (branco bege), marrom quente e pequenos detalhes dourados. O off-white deve ser a cor predominante, com o verde escuro aparecendo em áreas de destaque. O dourado deve ser utilizado apenas como detalhe delicado.

O design deve ser elegante e acolhedor, com fotografias de velas acesas, ambientes aconchegantes, madeira, linho, folhas, flores e iluminação quente. Evite aparência infantil, cores vibrantes ou excesso de elementos.

No topo do site, coloque o nome:

FOLHIÊ

E a frase:

“luz que guia, aroma que inspira.”

Crie um menu de navegação com as seguintes abas:

CONHEÇA OS PRODUTOS
COLEÇÃO
SAIBA MAIS SOBRE NÓS

Na página inicial, criar um grande destaque com uma vela aromática e o texto:

Aromas que transformam momentos.

“Velas aromáticas feitas para trazer aconchego, beleza e personalidade para cada espaço.”

Adicionar um botão escrito:

CONHEÇA NOSSOS PRODUTOS

Criar uma seção CONHEÇA OS PRODUTOS com uma apresentação visual de diferentes velas aromáticas, utilizando cartões elegantes com espaço para foto, nome, aroma e preço.

OUTONO — aromas quentes e acolhedores.
INVERNO — aromas profundos e envolventes.
PRIMAVERA — aromas florais e delicados.
VERÃO — aromas leves e tropicais.
